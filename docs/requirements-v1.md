# 玩具加工管理系统 —— 第一版需求文档

> 玩具加工 SaaS，暂定名「玩具加工管理系统」

## 核心能力
- 多玩具厂管理
- 产品管理
- 入库单 AI 识别（OCR）
- 加工费用计算
- 应收账单管理

## 一、系统角色
第一版：**单用户模式**，老板/管理员一人管理所有玩具厂数据。
暂不实现：用户管理、权限管理、多角色。

## 二、系统模块结构
```
首页 Dashboard

基础资料
 ├── 玩具厂管理
 └── 产品管理

业务管理
 └── 入库管理

财务管理
 └── 应收账单
```

## 三、首页 Dashboard
目标：老板打开系统快速了解经营情况。

- **今日数据**：今日入库单数量 / 今日加工数量 / 今日加工金额
- **本月数据**：本月加工金额 / 本月入库次数 / 本月加工数量 / 未收款金额
- **玩具厂排行**：按本月加工金额排序（如 A厂 50,000 元 / B厂 30,000 元）
- **待处理提醒**：待确认入库 / 数量异常 / 未收款账单

## 四、玩具厂管理
维护合作玩具厂。

| 字段 | 说明 |
|---|---|
| 玩具厂名称 | 必填 |
| 联系人 | 可选 |
| 电话 | 可选 |
| 地址 | 可选 |
| 备注 | 可选 |

列表字段：玩具厂名称 / 联系人 / 联系电话 / 产品数量 / 加工金额 / 操作（新增、编辑、删除、查看）

## 五、产品管理
产品归属于具体玩具厂（一对多）。

| 字段 | 说明 |
|---|---|
| 所属玩具厂 | 必填 |
| 货号 | 必填 |
| 名称 | 必填 |
| 工厂价 | 元/个，玩具厂支付给我们的加工价格 |
| 加工价 | 元/个，外放加工支付的价格 |
| 备注 | 可选 |

第一版暂不使用「加工价」计算利润。

## 六、入库管理（核心模块）

### 业务流程
```
上传图片 → AI OCR识别 → 人工确认 → 生成入库记录 → 生成加工金额
```

### 入库单字段
基础信息：入库单号（系统生成）/ 玩具厂（必填）/ 入库日期（图片识别）/ 图片（保存）

产品信息：货号 / 名称 / 重量（斤）/ 单个克重 / 数量 / 工厂价 / 金额 / 备注

### 数量计算逻辑
```
数量 = 重量(斤) × 500 ÷ 单个克重(g)
例：100斤，单个50g → 100×500÷50 = 1000个
```

### 数量异常处理
若入库单填写数量（如 980）与系统计算数量（如 1000）不一致：
- 提示「数量存在差异」，展示入库单数量 / 系统计算数量 / 差异
- 人工选择：使用入库单数量 或 使用系统计算数量
- 差异自动记录进备注

### AI 识别规则
- 支持图片上传，识别：玩具厂 / 产品 / 货号 / 重量 / 单个克重 / 数量 / 日期
- 玩具厂识别失败 → 提示人工选择
- 日期识别失败 → 默认当天
- 数量字段缺失 → 系统按公式计算

### 入库记录操作
- 搜索条件：玩具厂 / 日期 / 产品名称 / 货号 / 入库单号
- 修改：允许直接修改，修改后自动重新计算金额并同步更新账单
- 删除：支持，但需二次确认

## 七、应收账单
- **实时计算**，不生成固定账单
- 查询条件：玩具厂 + 时间范围
- 加工金额 = 最终数量 × 工厂价

页面展示：
- 汇总：玩具厂 / 时间（如 2026年8月）/ 入库次数 / 加工数量 / 加工金额 / 状态
- 明细：日期 / 货号 / 名称 / 数量 / 工厂价 / 金额
- 收款状态：人工在「未收款」「已收款」之间切换，**不记录**收款金额、收款日期、收款方式（第一版从简）

## 八、UI 开发要求
风格参考：**Soybean Admin + Element Plus**
- 左侧菜单 + 顶部 Header + Tab 页面
- Element Plus 组件风格，数据密度高，企业后台感

**不要**：引入 soybean 后端、权限系统、复杂 Mock 服务

页面重点 —— **入库管理页面**：
- 左侧：上传区域（上传入库单图片）
- 右侧：OCR 结果编辑表单
- 状态流转：识别中 → 待确认 → 已完成
